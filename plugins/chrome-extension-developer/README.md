# chrome-extension-developer (plugin)

Claude Code plugin with one skill, `chrome-extension-developer`, that guides Claude through building,
maintaining, debugging, auditing, migrating and publishing Google Chrome extensions on Manifest V3,
following the official Chrome documentation. It ships deep reference files, a zero-dependency
manifest linter (`scripts/check_manifest.py`) and a runnable starter template.

Invoke it as `/chrome-extension-developer:chrome-extension-developer`, or just ask Claude about a
Chrome extension and it loads automatically. See the repository README for installation and usage.
